# go-weave 技术白皮书 · Technical Whitepaper

这份文档体系解释 go-weave 如何工作——如何在运行时伪造 `itab`、JIT 生成机器码、伪造 `moduledata`，让 Go 拥有 Java 式的动态代理 / AOP。

This document set explains how go-weave works — forging `itab`s, JIT-generating machine code, and forging a `moduledata` at runtime, to give Go Java-style dynamic proxies / AOP.
